# WaiterApp

O WaiterApp é uma ferramenta projetada para facilitar o trabalho de garçons, agilizando o processo de atendimento e gestão de pedidos. O objetivo do app é melhorar a eficiência dos serviços em restaurantes, bares e cafés.

## Objetivos de Aprendizados

- Elevar o conhecimento em backend utilizando express
- Elevar o conhecimento em banco de dados
- Elevar o conhecimento em desenvolvimento mobile (React Native)
- Elevar o conhecimento em desenvolvimento front-end com React utilizando WebSockets


## Tecnologias Utilizadas

- Node.js
- Express
- MongoDB
- WebSockets
- React
- React Native
